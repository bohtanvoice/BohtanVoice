About Us

BohtanVoice is an independent project dedicated to blending modern animation with the preservation of cultural heritage. We create high-quality translations and professional voiceovers in the unique Bohtan dialect, bringing beloved stories closer to a global audience.

About the Project

The Bohtan dialect is one of the rarest forms of Neo-Aramaic still spoken today, carried by only a small number of families. This project exists to give it new life through animation, so viewers can hear the language in a living, everyday context rather than only in academic records.
